## 📋 功能说明

这是 AddConfigModal React 组件的纯静态 HTML/CSS/JS 版本，支持三种状态：

### 状态 1: 改造前
- 投放渠道选择
- 跳转链接输入框

### 状态 2: 改造后 - 跳转尾量
- 投放渠道选择
- 跳转类型选择（默认：跳转尾量）

### 状态 3: 改造后 - 跳转链接
- 投放渠道选择
- 跳转类型选择（默认：跳转链接）
- 链接输入框（动态显示）

## 📝 使用说明

1. 打开页面后，顶部有状态切换控制面板
2. 点击不同按钮切换三种状态
3. 填写表单并点击"确认"查看提交结果
4. 所有交互都在浏览器控制台有日志输出
