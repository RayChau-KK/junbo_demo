## 快速开始

### 首次使用

1. **注册账号**
   - 访问 http://localhost:3000
   - 点击"注册"按钮
   - 填写邮箱和密码
   - 完成注册

2. **创建第一个项目**
   - 登录后进入工作台
   - 点击"新建项目"
   - 填写项目名称和描述
   - 点击"创建"

3. **开始使用 AI 助手**
   - 在项目中点击"AI 助手"
   - 输入您的需求
   - AI 将帮您生成文档或提供建议

## 核心功能

### 1. 项目管理

#### 创建项目
1. 点击顶部导航栏的"项目"
2. 点击"+ 新建项目"
3. 填写项目信息：
   - 项目名称（必填）
   - 项目描述
   - 项目状态（规划中/进行中/已完成）
4. 点击"保存"

#### 管理项目
- **查看项目列表**：在项目页面查看所有项目
- **编辑项目**：点击项目卡片右上角的"编辑"图标
- **删除项目**：点击"删除"图标（谨慎操作，会删除所有关联数据）

### 2. 知识库管理

#### 创建文档
1. 进入项目详情页
2. 点击"文档"标签
3. 点击"+ 新建文档"
4. 选择文档类型：
   - 📝 笔记：日常记录和想法
   - 📄 PRD：产品需求文档
   - 🏗️ 架构：架构设计文档
   - 🔄 流程：业务流程文档
5. 编写内容并保存

#### 使用 AI 生成文档
1. 创建新文档时，点击"AI 辅助"
2. 输入文档主题或关键信息
3. AI 将生成文档大纲或初稿
4. 您可以继续编辑和完善

#### 文档标签
- 为文档添加标签便于分类
- 支持多标签
- 可通过标签筛选文档

### 3. 需求管理

#### 创建需求
1. 进入项目详情页
2. 点击"需求"标签
3. 点击"+ 新建需求"
4. 填写需求信息：
   - 标题
   - 详细描述
   - 优先级（低/中/高/紧急）
   - 验收标准
5. 保存需求

#### 需求状态管理
需求有以下状态：
- 📝 **草稿**：初步想法，待完善
- 👀 **评审中**：等待评审
- ✅ **已批准**：评审通过，可实施
- 🚀 **已实现**：已开发完成
- ❌ **已拒绝**：不予实施

拖拽需求卡片可快速更改状态。

### 4. AI 智能助手

#### 文档生成
**场景**：快速生成 PRD、功能设计文档

**使用方法**：
1. 选择或创建文档
2. 点击"AI 辅助"按钮
3. 输入提示词，例如：
   ```
   帮我写一份社交 APP 的用户注册功能 PRD，
   包括：用户画像、功能需求、验收标准
   ```
4. AI 生成内容后，您可以继续编辑

#### 需求分析
**场景**：分析用户需求，提炼核心功能

**使用方法**：
1. 在需求页面点击"AI 分析"
2. 输入原始需求描述
3. AI 将帮您：
   - 提炼核心需求
   - 识别优先级
   - 建议功能拆分
   - 提供实现建议

#### 智能问答
**场景**：产品设计决策、最佳实践咨询

**使用方法**：
1. 点击右下角的"AI 助手"图标
2. 输入问题，例如：
   ```
   如何设计一个高效的用户反馈系统？
   移动端和 Web 端的产品设计有什么区别？
   ```
3. AI 将基于产品管理最佳实践回答

2. 按主题创建文档分类

**步骤**：
1. 创建"竞品研究"项目
2. 为每个竞品创建分析文档
3. 使用 AI 辅助提炼核心功能
4. 整理优势和可借鉴点
5. 形成自己的产品策略

## 最佳实践

### 1. 项目组织
- 按产品线或业务模块创建独立项目
- 使用清晰的命名规范
- 及时更新项目状态
- 定期归档已完成项目

### 2. 文档编写
- 使用 Markdown 格式，结构清晰
- 为文档添加有意义的标签
- 重要文档定期备份
- 善用 AI 辅助，但要人工审核

### 3. 需求管理
- 需求描述要清晰、可衡量
- 优先级评估要合理
- 验收标准要明确
- 及时更新需求状态

### 4. AI 使用技巧
- **提示词要具体**：不要问"写个 PRD"，而要说明功能、用户、场景
- **迭代优化**：AI 生成的内容可以继续提问优化
- **人机协作**：AI 辅助生成框架，人工补充细节
- **保留上下文**：在同一会话中连续提问，AI 会记住之前的内容

### 5. 效率提升
- 使用快捷键快速操作
- 创建常用文档模板
- 利用标签系统分类
- 定期回顾和总结

## 常见问题

### Q1: 如何修改已生成的 AI 内容？
A: AI 生成的内容都是可编辑的，直接在编辑器中修改即可。您也可以选中部分内容，让 AI 重新生成。

### Q2: 文档会自动保存吗？
A: 是的，文档会自动保存草稿。但建议重要修改后手动点击"保存"按钮。

### Q3: 可以导出文档吗？
A: 目前支持导出为 Markdown 格式。未来版本将支持 PDF、Word 等格式。

### Q4: AI 生成的内容准确吗？
A: AI 会基于产品管理最佳实践生成内容，但仍需要您根据实际情况审核和调整。AI 是辅助工具，最终决策权在您。

### Q5: 如何使用自己的 AI API Key？
A:
1. 在后端项目根目录找到 `.env` 文件
2. 修改 `ANTHROPIC_API_KEY=你的API密钥`
3. 重启后端服务

### Q6: 数据存储在哪里？
A: 所有数据存储在本地 PostgreSQL 数据库中，完全私有，不会上传到外部服务器。

### Q7: 可以多人协作吗？
A: 当前版本主要面向个人使用。多人协作功能在开发路线图中，预计在 Phase 4 实现。

### Q8: 如何备份数据？
A:
```bash
# 导出数据库
docker exec -t superpm-postgres pg_dump -U superpm superpm > backup.sql

# 恢复数据库
docker exec -i superpm-postgres psql -U superpm superpm < backup.sql
```
